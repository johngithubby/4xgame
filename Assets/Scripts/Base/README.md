# Base Scripts

## Files

- `BaseHudController.cs`: Displays local credits in an expandable button, dismisses building popup arrows before toggling credit details, shows coins, HQ level/status, and bio-lab level/status inside the expanded detail panel, keeps owned hero level/XP and equipped hero state visible, and exposes collect, HQ upgrade, daily objective claim, direct mission selection, play, heroes, equip hero, zoom, and development reset button actions.
- `BaseCameraController.cs`: Controls Base scene zoom through on-screen buttons, mouse wheel, keyboard shortcuts, and two-finger pinch, and pans the Base map through bounded mouse/one-finger dragging while ignoring HUD-origin gestures.
- `BaseSceneBootstrap.cs`: Builds the Phase 2/V6/V6-1 base scene at runtime, loads local progress, rolls over the local daily objective, completes ready HQ and bio-lab upgrades, grants HQ milestone hero rewards, creates an oversized unoutlined base floor, future gate/resource/hangar/training reserved spaces with the training pad offset away from the HQ for visibility, creates the reference-textured HQ and bio lab by loading `Resources/HQ/HQReferenceCutout` and `Resources/BioLab/BioLabReferenceCutout`, draws those concept images on camera-facing world quads, loads their blurred silhouette textures for matching completion auras, keeps the handmade HQ/body/lab pieces hidden as interaction/progression scaffolding, creates flat 2D popup upgrade arrows plus circular timers that start and show the saved upgrade timers, hides the occupied lab pad renderer, lays out a phone-sized HUD with an expandable credits control, direct mission buttons, and zoom buttons, saves direct mission button selection and daily objective claim changes, shows base feedback messages, and navigates to the minigame or Hero scene.
- `BioLabBuilding.cs`: Mirrors saved bio-lab level onto the reference-textured model and hidden scaffold, reveals a green/grey clickable flat 2D upgrade symbol based on local credits, hides that symbol on other world taps, displays a world-space circular progress fill while the timer runs, keeps the footprint and color stable, clears legacy exterior add-ons, raises the visible reference model and hidden lab body by a few pixels per level, positions the pulsating completion aura as a softly padded duplicate of the exact reference silhouette, and plays local pop/aura/sound feedback when an upgrade completes.
- `HQBuilding.cs`: Mirrors saved HQ level onto the reference-textured pentagon HQ and hidden scaffold, keeps the footprint and color stable, clears legacy generated detail rows, raises the visible reference model and hidden body by a few pixels per level, hides the generated label when the reference art is available, routes short mouse/touch taps on the visible HQ bounds to reveal a green/grey flat 2D popup upgrade arrow, hides that symbol on other world taps, routes popup-arrow taps to the saved upgrade request, displays a world-space circular progress fill while the timer runs, and positions the pulsating completion aura as a softly padded duplicate of the exact HQ silhouette.

## Compile

Unity compiles these files as part of the `LaneSurvivor.Runtime` assembly.

## Behavior

The base scene is local-only. It lets the player collect coins, spend coins on timed HQ upgrades by using the HUD button or by tapping the HQ then its popup upgrade arrow, spend coins on timed bio-lab upgrades by tapping the bio lab then its upgrade symbol, dismiss building popup arrows by tapping another building, empty map space, or HUD action, expand the Credits button to inspect coins, HQ level, bio-lab level, and upgrade status, claim a completed daily objective, persist progress locally, select among unlocked missions with numbered buttons, inspect the reference-textured pentagon HQ and reference-textured bio lab on an unoutlined base floor, zoom and drag the world camera without moving overlay HUD controls, see running HQ and bio-lab upgrade timers as circular world-space progress fills, see upgrade-complete feedback with pulsating blurred silhouette auras around the exact HQ or lab outline alongside any milestone hero reward, see the HQ and bio lab grow only slightly taller with each level and no exterior equipment, see the minigame coin/hero/mission reward hint, view owned hero levels and XP, cycle equipped heroes, open the dedicated Hero screen, reset local progress in editor/development builds, and launch the minigame with the selected mission plus HQ-derived and hero-derived bonuses. The lab pad keeps its logical object but no longer draws a slab or separate `LAB` pad label once occupied, and the generated placeholder geometry uses shared material creation so iOS player builds do not depend on one specific shader name.
